# IE Painter Starter Plugin

A tiny starter template for Substance 3D Painter plugin development.

## Install

1. Copy this folder into your local Substance Painter plugins directory.
2. Restart Painter.
3. Enable plugin and run: `Plugins > IE Starter > Say Hello`.

## What this template demonstrates

- `start_plugin()` and `close_plugin()` lifecycle.
- Basic menu/action registration.
- Safe cleanup for reload/unload.
- Minimal logging helper.

## Extend ideas

- Batch exporter by naming convention.
- Texture set validation rules.
- Pipeline integration for DCC/game engine.
